# MareSat

Protótipo web desenvolvido para a Global Solution 2026/1 da FIAP.

O MareSat apresenta uma solução de navegação inteligente baseada em correntes oceânicas, com foco em economia de combustível, redução de emissões e segurança para diferentes tipos de embarcação.

## Páginas

- `index.html`: apresentação do projeto, problema, funcionamento, modos de uso e impacto estimado.
- `ocean.html`: painel para simular rotas oceânicas com dados fictícios de corrente, vento, onda, economia e CO₂ evitado.
- `coastal.html`: modo costeiro com mapa simplificado, alerta de segurança e zonas favoráveis para pesca.

## Estrutura

- `css/style.css`: estilos gerais do projeto.
- `js/ocean.js`: lógica da simulação de rota oceânica.
- `js/coastal.js`: troca de zonas e atualização do painel costeiro.
- `img/maresat_logo.svg`: logo do MareSat.

## Como abrir

Basta abrir o arquivo `index.html` no navegador. As demais páginas podem ser acessadas pelo menu principal.
